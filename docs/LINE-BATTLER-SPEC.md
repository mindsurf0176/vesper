# 베스퍼 회랑 — 실시간 라인 배틀러 계약

## 한 문장

플레이어는 코스트를 모아 소규모 출격대를 전장에 투입하고, 전선과 오브 명령을 조절해 적 매듭을 파괴한다.

## GameSpec

### 한 판의 흐름

1. 브리핑에서 이번 회랑의 적 웨이브와 변칙을 확인한다.
2. 5명 이하의 출격대를 선택한다.
3. 전투 중 손패에서 유닛을 선택하고 배치 위치를 지정한다.
4. 유닛은 이동과 기본 공격을 자동으로 수행한다.
5. 플레이어는 오브 커맨드, 지휘기, 소신, 후퇴로 전황을 바꾼다.
6. 적 매듭 HP가 0이면 승리, 등불함 HP가 0이면 패배한다.

### 플레이어가 책임지는 것

- 누구를 소환할지
- 언제 소환할지
- 어느 전선 깊이에 배치할지
- 어떤 오브 조합을 소비할지
- 코어 HP를 소신으로 태울지
- 지휘기를 언제 사용할지

### 런타임이 책임지는 것

- 이동, 사거리, 타겟 선택, 공격 주기
- 역할 상성 및 방어 계산
- 웨이브 스폰과 코어 피해
- 애니메이션 상태 전환
- 승패와 결과 기록

## MVP 전투 계약

| 항목 | 값 |
| --- | --- |
| 전투 길이 | 45초 이내 |
| 출격대 | 최대 5명 |
| 동시 아군 | 최대 7명 |
| 손패 | 4장 순환 |
| 시작 코스트 | 3 |
| 최대 코스트 | 10 |
| 기본 코스트 회복 | 초당 0.7 |
| 오브 발동 | 1 / 2 / 4개 |
| 승리 | 적 매듭 HP 0 |
| 패배 | 등불함 HP 0 또는 제한시간 종료 |

## 역할 계약

- 스트라이커: 전선을 열고 적 원거리 유닛을 압박한다.
- 레인저: 중거리에서 안정적으로 적을 줄인다.
- 디펜더: 전선을 고정하고 코어 피해를 지연한다.
- 스나이퍼: 긴 준비시간을 감수하고 우선순위 대상을 처형한다.
- 서포터: 회복과 코스트 보조를 제공한다.

역할은 자동 전투의 숫자 태그가 아니라, 플레이어가 소환 순서를 판단하는 이유가 되어야 한다.

## AssetSpec

### 전투 캐릭터

- 카메라: 고정 HD-2D 사이드뷰
- 렌더 방식: AnimatedSprite3D 빌보드
- 필수 상태: idle, walk, aim, attack, hit, death
- 공통 발 기준선: 월드 Y=0
- 전투 표시 높이: 캐릭터별 1.34~1.95m
- 팀 방향: 아군 우향, 적군 좌향
- 전투 에셋이 없는 캐릭터는 플레이스홀더 도형으로 승격하지 않고 asset_blocked 상태로 남긴다.

### 일러스트와 UI 에셋

- hero 일러스트: 브리핑, 결과, 캐릭터 상세
- face/card 컷아웃: 손패와 출격대
- 전투 스프라이트: 전장 상호작용 전용
- 일러스트를 전투 충돌체나 플레이어 조작 표면으로 사용하지 않는다.

## 대회용 버티컬 슬라이스

첫 제출 빌드는 아래만 완성도 있게 닫는다.

- 라온을 포함한 5명 출격대
- 1개 회랑, 3개 웨이브, 1개 보스 변형
- 카드 소환과 위치 지정
- 오브 1/2/4 명령
- 소신과 지휘기
- 승리/패배 결과
- 전투 중 되감기나 복잡한 메타 성장 없음

## 전황 가독성

- 상단 HUD는 코어 HP와 함께 `아군 전선 우세 / 전선 균형 / 전선 밀림`을 표시한다.
- 등불함 HP가 30% 이하이면 위험 배너를 표시하고, 적 매듭 HP가 25% 이하이면 마무리 배너를 표시한다.
- 전투 중 `지휘기`를 사용할 수 있다. 12초 쿨다운으로 적 전장 유닛 전체에 즉시 피해를 주며, 자동 전투에 한 번의 수동 개입 타이밍을 만든다.
- 자동 전투의 판단 지점은 손패·출격 순서·오브·소신이며, 전황 HUD는 개입 타이밍을 읽기 위한 정보만 제공한다.

상점, 모집, 패스, 채팅, 장기 성장 화면은 버티컬 슬라이스 이후에 다시 연결한다.
