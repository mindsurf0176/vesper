# Vesper Tactical 3v3

## Playable verb

편성한 3명의 전투원으로 적의 다음 행동을 읽고, 공격·방어·교대·공명을 선택해 상대 3명을 전부 쓰러뜨린다.

## Match contract

- 양 팀은 3명으로 구성한다.
- 한 라운드에 양 팀의 활성 전투원 1명씩만 전장에 선다.
- 플레이어는 매 턴 `공격`, `방어`, `필살`, `교대` 중 하나를 선택한다.
- 적 행동은 `공격`, `방어`, `필살 충전`, `회복` 중 하나로 사전 예고한다.
- `교대`는 쓰러지지 않은 아군으로 활성 전투원을 바꾸며, 교대한 턴에는 공격하지 못한다.
- 활성 전투원의 HP가 0이면 자동 교대한다. 세 명이 모두 쓰러지면 패배한다.
- 한 전투는 8~12턴 안에 끝나도록 피해량과 회복량을 조정한다.

## Character roles

- Striker: 공격 예고를 끊으면 추가 피해.
- Ranger/Sniper: 방어 관통, 안정적인 장거리 피해.
- Defender: 방어 후 반격, 아군 보호.
- Support: 회복, 약화 해제, 필살 게이지 지원.

## Signature system: constellation resonance

행동 성공 시 캐릭터의 별자리 노드가 1개씩 연결된다. 다음 세 조합이 완성되면 팀 공명을 발동한다.

- `방어 성공 → 공격`: 반격 공명, 다음 공격 피해 증가.
- `교대 → 필살`: 계승 공명, 새 전투원의 필살 게이지 증가.
- `공격 → 공격 → 공격`: 돌파 공명, 적 방어를 무시한다.

## UI contract

- 왼쪽: 아군 3명 초상, HP, 활성 표시.
- 중앙: 활성 전투원 두 명, 행동 연출, 적 행동 예고.
- 오른쪽: 적 3명 초상, HP, 쓰러짐 표시.
- 하단: 공격/방어/필살/교대 버튼과 현재 공명 진행도.
- 전투 화면은 1280x720 기준으로 만들고, 버튼은 모바일 터치도 가능하게 한다.

## QA gates

- 3명 편성에서 같은 캐릭터 중복이 방지된다.
- 행동 예고와 실제 판정이 결정론적으로 일치한다.
- 교대 후 이전 전투원의 HP와 게이지가 보존된다.
- 활성 전투원 사망 시 자동 교대하고, 세 명 사망 시 결과 화면으로 이동한다.
- 공명 세 조합이 각각 한 번씩 발동한다.
- Web export와 모바일 가로 화면에서 HUD가 겹치지 않는다.
