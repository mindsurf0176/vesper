# Vesper: Endless Corridor Roguelite

## Core loop

라인배틀러 출격대와 경제를 유지한 채, 매 런마다 달라지는 회랑의 노드를 선택한다. 전투·보급·이벤트를 통과하며 편성과 보상을 조정하고, 마지막에 회랑의 수문장을 쓰러뜨린다. 전멸하면 런이 끝나고 다음 런은 새로운 시드로 시작한다.

## Why this fits the current asset pack

캐릭터와 배경을 계속 새로 만들지 않는다. 기존 스프라이트·초상·역할 아이콘·별자리·이펙트를 다음 데이터 조합으로 재사용한다.

- 같은 캐릭터의 적/아군 역할 변경
- 전투 규칙 변형
- 적 편성·행동 패턴 변경
- 보상과 유물 조합
- 노드 선택과 이벤트 결과

## Run contract

- 시작 시 기존 라인배틀러 출격대를 준비한다.
- 맵은 짧은 분기 노드 4개로 생성한다.
- 노드 타입은 `전투`, `엘리트`, `보급`, `이벤트`, `회복`, `보스`다.
- 일반 전투, 엘리트, 이벤트를 거쳐 보스에 도달하면 클리어한다.
- 전투는 기존 `CombatSim` 라인배틀러가 처리한다.
- 플레이어는 손패·코스트·배치·오브·지휘기·소신으로 전투에 개입한다.
- 전투 후 생존자·코어 피해·경제 상태가 다음 노드로 이어진다.
- 등불함 HP가 0이면 런 종료. `seed`를 저장해 같은 런을 재현할 수 있다.

## Endless content from data

### Mutators

노드와 전투마다 1~3개의 변칙을 조합한다.

- `붕괴하는 회랑`: 5턴마다 모든 유닛에게 피해
- `과열`: 필살기 피해 증가, 사용 후 HP 감소
- `잔향`: 첫 번째로 쓰러진 캐릭터가 적에게 약화 효과 부여
- `무음`: 회복량 감소, 방어 성공 시 게이지 증가
- `쌍성`: 같은 속성 캐릭터가 연속 행동하면 추가 피해

### Rewards

보상은 수치와 태그를 섞어 생성한다.

- 공격력·최대 HP·회복량·필살 게이지
- 캐릭터 태그: `돌격`, `방어`, `사격`, `지원`
- 행동 태그: `교대`, `가드`, `필살`, `연속`
- 매 런 3~5개의 유물만 장착해 빌드를 만든다.

### Enemy generation

적은 기존 캐릭터 스프라이트를 재사용하고, `역할 + 행동 패턴 + 변칙`으로 새 개체를 만든다.

- 선봉: 공격 예고가 자주 나타남
- 수문장: 방어와 도발 중심
- 추적자: 체력이 낮은 아군 우선 공격
- 공명체: 같은 속성 아군이 있으면 강화

## MVP scope

- 기존 라인배틀러 준비 페이즈
- 라인 전투 1종
- 노드 4개짜리 짧은 런
- 변칙 3종
- 유물 6종
- 보스 1종
- 승리·전멸·다시 시작
- seed 기반 런 생성

콘텐츠 수는 코드가 아니라 데이터 배열로 늘린다. 따라서 에셋을 추가하지 않아도 적 조합, 변칙, 보상, 맵 시드를 계속 확장할 수 있다.
